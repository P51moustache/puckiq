## Description

PuckIQ is the weekly lines board for YOUR roster. Open the app, type a name, tap F (or D, G, bench). One roster. This week only.

Not NHL picks. Not fantasy. Not news.

**What’s New (this run)**

- Empty roster / first add: type a name on Lines, tap F. That player is on this week’s line.
