# PuckIQ screen concepts

Generated with the built-in imagegen tool. Each board explores Tonight, Week, and Pickups using PuckIQ's existing warm-paper, white, carbon-black, and racing-red palette.

- [01 — Pit Wall](01-pit-wall.png): Compact sports dashboard with timing panels, coach actions, and dense schedule detail.
- [02 — Coach Brief](02-coach-brief.png): Spacious editorial layout that puts the next useful decision first.
- [03 — Rink View](03-rink-view.png): Spatial lineup diagram and open-slot grids that make roster gaps visible.

Coach Brief is the strongest starting point for quick nightly decisions. Pit Wall offers more detail at once; Rink View is the most exploratory.

These are generated design explorations with illustrative player content and metrics. Fine text, positions, availability percentages, and schedule totals are sample content, not validated NHL data or production behavior.

Palette source: `components/coach/ui.tsx`. Current navigation source: `app/(tabs)/_layout.tsx`. Existing raw screenshots informed the design brief.

The full prompt set is saved in [prompts.json](prompts.json).
