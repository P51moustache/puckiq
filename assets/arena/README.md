# Arena Club assets

`skater.png` is the original fictional hockey-player illustration generated for the approved Arena Club concept on 2026-09-09. It does not depict an identified NHL player and must not be labeled as one. `ArenaSkater` desaturates it in the native SVG renderer so the equipment does not imply a different home team.

Typography is bundled for offline use. Teko SemiBold is a static weight-600 instance of Google Fonts' `ofl/teko/Teko[wght].ttf`; DM Sans uses the original variable file from `ofl/dmsans/DMSans[opsz,wght].ttf`. Their SIL Open Font Licenses are adjacent to the font files. Font sources: https://github.com/google/fonts/tree/main/ofl/teko and https://github.com/google/fonts/tree/main/ofl/dmsans.
